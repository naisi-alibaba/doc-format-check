# 规则与保护范围



依据：**指** = 排版指北；**工** = Markdown 语法；**项** = profile。

### A 档 · 可自动修（16 条）

| ID | 规则 | 依据 | 说明 |
| --- | --- | --- | --- |
| F01 | 列表标记后补空格 | 工 | `-文字` / `1.文字` 不是合法列表项 |
| F02 | 混排文字/条件符号之间加空格 | UTR59+项 | 「在 LeanCloud 上」 |
| F03 | 项目专名 | 项 | profile `project_names` |
| F04 | 分节标题层级 | 项 | profile 设 `heading_level` 时才检查 |
| F05 | 标题/列表前后补空行 | 工 | 列表紧贴标题会渲染塌陷 |
| F06 | 清多余空白 | 工 | 无语义的行尾空格、全角空格（保留两个空格的 Markdown 硬换行）、Tab、开头空行、连续多空格 |
| F07 | 路径分隔符统一 ` > ` | 项 | 仅路径标签行，或「」内含 `path_context` 词/已有 `>` |
| F08 | 路径标签去加粗 | 项 | `**前往路径：…**` → 普通文本 |
| F09 | 技术专名大小写 | 指 | `github`→GitHub、`ios`→iOS、`wifi`→Wi-Fi、`typec`→Type-C |
| F10 | 东亚文字与数字间加空格 | UTR59+项 | 「花了 5000 元」。`--num-space never` 可关 |
| F11 | 数字与单位间加空格 | 指 | 「20 TB」「5000 mAh」 |
| F12 | 删全角标点旁空格 | 指 | `「iPhone ，」` →「iPhone，」 |
| F13 | 压缩重复标点 | 指 | `「！！！」` →「！」，只压同字符 |
| F14 | 半角标点转全角 | 指 | `,;:?!.()`，左侧须为汉字或中文右括号/右引号 |
| F15 | 全角数字/字母转半角 | 指 | `１０００` → 1000 |
| F16 | 错别字/错别单词 | 内置+项 | 内置中英文常见错字，英文保留原大小写 |

**F16 准入门槛**：默认只自动处理内置常见错字；“帐号/部份/定单/象素”等字形或语境偏好只报 B08。需要统一时由项目 profile 显式配置。
`按装`/`seperate` 进 F16；`登陆`（登陆作战）、`须要`、`其它` 只能进 B08。
项目补充用 profile 的 `typo_fix`，关掉内置某条用 `typo_fix_disable`。
**词典驱动，不是全量拼写检查**，词典外的错字一律抓不到。

### 例外（删任何一条都会改坏文档）

- **保护区掩码**：代码、链接、图片、URL、域名、带扩展名文件名、版本号、时间，不参与检测与修改。
- **品牌白名单**：官方不带空格的写法（如 `豆瓣FM`）走 profile `no_space_brands`，F02 不加空格。
- **英文整句内半角标点保留**：`「Stay hungry, stay foolish.」`、`See (fig 1)?` 不转全角。
- **度数与百分比**：`90°`、`15%` 不加空格，且反向删掉已有空格。
- **`W` 不进单位表**：可能是功率也可能是「万」，交 B09。
- **行首语法前缀隔离**：`- `、`1. `、`> `、`### ` 后的空格是语法的一部分，先切下前缀再处理正文。
- **分隔线守卫**：`---` / `***` / `___` 不进 F01；YAML frontmatter 与围栏代码块整段跳过。
- **表格单元格内边距**：`|` 两侧的空格不算「标点旁空格」，F12 不动。

### B 档 · 只报不改（13 条）

| ID | 规则 | 依据 | 不能自动改的原因 |
| --- | --- | --- | --- |
| B01 | 内部标记残留 | 项 | 删了等于把未决问题掩埋 |
| B02 | 第三方名称待裁定 | 项 | 归属确认前替换就是编造功能 |
| B03 | 普通标签被加粗 | 项 | 有的加粗是界面原文强调 |
| B04 | 有序列表疑为并列 | 工 | 整块 ≥2 条为「标签：说明」式才报，整块报一次 |
| B05 | 常见问题缺「？」 | 项 | 可能内容本就不是问句 |
| B06 | 空小节 | 工 | 补内容还是删标题由内容决定 |
| B07 | 绝对化/不可核验表述 | 项 | 对外承诺必须相关方确认 |
| B08 | 疑似错字、重复字、易混词 | 项 | 有歧义的词要看语境 |
| B09 | `数字+W` 疑似当「万」 | 项 | 可能是功率、型号 |
| B10 | 路径写法不一致 | 项 | 哪个是真实界面脚本不知道 |
| B11 | H1 缺失或重复 | 工 | 标题文本要人定 |
| B12 | 不地道缩写 | 指 | 全称写法看语境 |
| B13 | 引号风格混用 | 指·争议 | 方向由项目定 |

**脚本抓不到的，人必须补看**：语义错字（多字、缺字、串词）、同一内容两处重复展开、菜单名与实际界面不符。
**规则噪音也是 bug**：一条 B 档规则若对正常文档大面积命中，要么加收敛条件，要么按块汇总。


缩进代码和引用定义保守跳过；支持不同长度的反引号/波浪线围栏。该工具不是完整 Markdown 解析器；复杂嵌套 HTML 或自定义语法应先只扫并审阅差异。

UTR59分类、字素边界、语言及句读适配见 [spacing.md](spacing.md)。UTF-8输出不改变原文件编码/BOM与换行保护。
